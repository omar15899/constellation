# Constellation

Las rutas de este perfil se interpretan desde la raíz del checkout local de Constellation.
Las reglas de dominio se conservan; versiones y comandos se contrastan con los archivos actuales.
La coordinación y publicación usan el único `constellation.py`.

Constellation posee los agentes, skills, perfiles, instalación, hooks y flujo de revisión/publicación. Las sesiones y preferencias personales pertenecen al cliente nativo.
