# Command skills

These workflows have one canonical Markdown source each. Claude exposes commands;
Codex projects them as skills invoked with `$name`. Shared repository skills are
listed [separately](../skills/README.md); they need no duplicate command wrappers.

| Entry | Distinct responsibility |
| --- | --- |
| verify-loop | Execute, check, challenge, repair and finish a substantial task |
| quant-loop | Research validity: time, universe, causality, costs and inference |
| debug-metric | Trace a suspicious metric to its first verifiable divergence |
| gate-check | Assess a promotion or record an established lever verdict |
| repo-doctor | Health diagnostics and behavioral audit of the AI workflow |
| codex-sync | Safe targeted projection, drift and discovery checks |
| commit-research | Explicitly scoped commit/push workflow under task authority |
| video-asincrono | Brainteasers Quant videos using V8, definitive Markdown structure, Hespérides and adversarial truth/comprehension review |

Skills guide behavior; they are not deterministic enforcement. Hooks and tests
establish different facts, described in [hooks](../hooks/README.md) and
[Codex parity](../docs/codex_parity.md). Read task-specific contracts on demand;
no mandatory sequence of tiny prompt commands or ritual ledger updates.
