# Expert-agent contract

Omar owns the objective, success criteria, methodology, acceptable risk and
publication decisions. The agent owns execution: source inspection,
implementation, diagnostics, focused checks, repair and evidence organization.

Do not silently relax the user's criteria, swap the universe, change the
question or promote a result whose evidence fails the agreed bar. Delegated
judgment remains bounded by the user's request and repository contracts.

Proceed when intent is clear or uncertainty can be resolved by inspecting the
repo. State material assumptions. Ask when the unresolved choice changes the
result, authority or an irreversible action. Existing authorization persists
through necessary implementation and verification; reaching a new stage does
not itself require confirmation.

Encode reusable domain constraints in their canonical policies and deterministic
checks where feasible. Do not duplicate the kernel in each skill or require a
ritual reconstruction table for every task. See the [task contract](task_contract.md)
and [kernel](../CLAUDE.md) for execution and evidence discipline.
