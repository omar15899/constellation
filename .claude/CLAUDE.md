# Constellation compatibility entrypoint

Claude Code loads this file alongside the root `CLAUDE.md`. The active hub
contract is [the root entrypoint](../CLAUDE.md), which imports
[AGENTS.md](../AGENTS.md). Follow that shared lifecycle and the receiving
repository's own instructions, Git ownership, checks and publication policy.

This retained path supports existing readers. It introduces no separate router,
model selection, research ledger or completion loop. Historical commands and
role definitions remain available as resources when the task needs them; their
execution procedures are superseded by the active shared workflow.

Domain constraints remain in the existing [QuantOS architecture](../QUANTOS.md),
[perimeter doctrine](policies/perimeter_doctrine.md),
[tier discipline](policies/tier_discipline.md),
[promotion gate](contracts/promotion_gate.md) and
[AI invariants](policies/ai_invariants.md). Apply their relevant scientific and
authorization requirements without reintroducing historical publication chains.
Respect research verdicts marked DO-NOT-RE-RUN. Research does not authorize
real-money execution.

The Claude registry supplies domain context. The shared workspace registry and
actual Git owner determine routing and publication. Neighboring repositories
and OmarOS retain their own contracts and require explicit delegated scope.

Preserve local work, secrets and private conversation data. Use the native
client's model, effort, permissions and effective capacity. Keep hooks bounded
and local; acceptance depends on current checks and independent review.
