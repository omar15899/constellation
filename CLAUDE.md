This repository owns Constellation's shared research and engineering tools.
Claude and Codex use the same project ownership, evidence and publication rules:

@AGENTS.md

The portable Constellation plugin supplies canonical skills, native specialist
agents and Claude event adapters. Its source and laptop installation guide are
in [.codex/ecosystem/README.md](.codex/ecosystem/README.md). Another laptop receives
the same research contracts. Credentials, connector access, data, personal
profiles and task state remain local.

Use one existing lifecycle per objective. For this Git owner, use
`.codex/ecosystem/cli.py git --session claude-NATIVE_SESSION_ID`; for coordinated
owners, use `.codex/ecosystem/cli.py workspace` and the actual contracts of each
repository. Research without publication can use the shared portable CLI.
Obtain the native session
identity from the plugin context and pass it explicitly. Register actual author
and reviewer IDs without the lifecycle prefix.

Keep model, effort, permissions and effective concurrency under the native
client's control. The coordinator assigns exclusive paths and supplies relevant
invariants and evidence to agents. Source criticism, counterexamples, proofs,
experiments, failed attempts and unresolved obligations belong in the research
record. A model answer or source vote does not certify scientific correctness.

Historical research scripts, commands and contracts remain available as tools
when relevant. Their mandatory routers, model tiers, implicit ledger writes and
heuristic completion loops are superseded by the shared lifecycle. Do not load
historical orchestration layers to satisfy stale text. The compatibility entry
in `.claude/CLAUDE.md` points to this same shared contract.
The project retains its independent secret and syntax checks.

The `.codex/profile.json` projection marker remains in force. Installing the
plugin does not grant trust, start a task, publish data or enable a broker.
Verify native loading in a new Claude session; do not claim it from files alone.
