# /genesis

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Resolve the target Git owner and read its local instructions and current state.
Inventory existing automation, project data and native entry points; identify
what must be preserved. In `--dry-run` or `--preserve-only` mode, return the
inventory and proposed changes without writing. For an authorized installation,
use Constellation's common installer and central project profile. Keep only
native loading entry points in the target. Validate a real scoped edit and an
independent review before claiming the integration works. Preserve local changes,
Git history and working automation; report remaining limitations. The optional
`--phase` request narrows work to the requested audit, plan, installation,
integration or verification phase.
