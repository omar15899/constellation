# /project-refresh

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Resolve the single project and its configured repository. Fetch the expected
remote when authorized, preserving the branch, working tree and index. Use
`repo-reporter` to summarize the observed commit range in
`11_Documents_and_Reports/Project_State/<project>.md`, then `dashboard-builder`
for `17_Dashboards/Projects/<project>.md`. Inspect project-tagged tasks for stale
state; change task status only when supported by evidence and authorized scope.
Report each completed or failed step and next actions. Do not merge, pull or
write inside an external clone as part of reporting.
