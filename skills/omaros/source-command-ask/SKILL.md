# /ask

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Interpret the requested outcome, consult the relevant skills, and read only the
context needed. A question is answered in conversation; a requested file change
gets explicit paths and acceptance evidence. Ask only when a missing choice
materially changes the result. Do not expand a short request into an unrelated
system redesign. Search existing notes before creating content, and separate
facts, assumptions and unresolved questions. Use `/route` when the user wants
placement advice without a write.
