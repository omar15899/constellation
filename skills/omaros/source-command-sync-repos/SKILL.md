# /sync-repos

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Resolve the requested repository set from the current project registry and
any explicit filter. For each configured active root, fetch its expected remote
when authorized and inspect the range since the previous report. Never merge,
pull, alter worktrees or indexes, silently clone missing roots, or commit
upstream changes. Classify each result as ok, unchanged, failed, missing or skipped.

Use `repo-reporter` for reports under
`11_Documents_and_Reports/Project_State/<project>.md` and link them from
`11_Documents_and_Reports/Refresh/YYYY-MM-DD_sync_repos.md`. Record the exact
remote, branch and commit range observed. Explicitly distinguish remote fetch
from local integration and publication.
