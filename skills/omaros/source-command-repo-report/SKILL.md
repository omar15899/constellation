# /repo-report

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Use `repo-reporter`. Resolve the tracked repository and previous report,
then inspect the branch, HEAD, expected upstream and requested `since` range.
Read the repository without changing its worktree or index. Report dated commit
and file changes by theme, paths affected, open threads, relevant vault notes,
blockers and at most three evidence-backed next actions.

The destination is `11_Documents_and_Reports/Project_State/<project>.md` under
OmarOS. Preserve dated history and mark the observed range. Missing or stale
clones are limitations, not a successful complete report. Do not combine
unrelated repositories into a single project's state.
