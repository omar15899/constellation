# Preferred Learning Style

This is a **placeholder**. Omar will refine and expand it over time. The skill reads this file before designing a script and treats it as a list of stylistic and pedagogical commitments — not as a literary template.

## Things I value (intellectual style)

- **Motivation from necessity.** Definitions arrive as the answer to a problem the viewer feels. They are not declared by fiat.
- **Rigorous definitions.** Quantifiers are explicit; types are explicit; constraints are stated.
- **Powerful examples.** Examples are chosen so that the abstraction feels inevitable when it arrives — not as a token gesture.
- **Object-versus-representation distinction.** A coordinate expression is not the manifold; a sample path is not the process; a matrix is not the linear map. The distinction must be visible.
- **Special cases.** Used to illuminate the general case, never to *replace* it.
- **Non-examples.** When the boundary of a definition is subtle, a non-example sharpens it. Used sparingly; chosen surgically.
- **Pill of abstraction.** After enough examples, the structural pattern is named. The abstraction lands as recognition rather than as imposition.
- **Mathematical correctness.** Non-negotiable. Pedagogy simplifies the route, not the concept.
- **Movement from intuition to formal structure.** Visual intuition leads; formalism arrives at the right moment, neither too early nor too late.

## Things I dislike

- Generic explainer fluff: "buckle up", "let's dive in", "this is super important", "stay tuned".
- Bullet-point reveals masquerading as explanation.
- Metaphors that are never reconciled with the formal object.
- Examples presented as if they were definitions.
- Hedging or apology in mathematical language.
- Slick visuals with no conceptual function (decorative ornament).

## Audience self-model (for scripts written *for* me)

When the viewer is me:

- High mathematical density is fine.
- Skip motivational framing.
- Prefer the narrator to assume I am intelligent and to compress accordingly.
- Build from necessity → formalise → exercise on a non-trivial example.
- A 6-minute video can carry a dense definition; do not stretch it for accessibility.

## How the skill should treat this file

- Read this file before designing the script.
- Treat the bullets as design constraints, not as prose to copy.
- The script's narration must have its own grammar (timing, visuals, sync) — preserve the *intellectual* style without copying the *literary form* of these notes.
- When this file's preferences and a generic best practice conflict, prefer this file's preferences (it represents the actual user, not an averaged learner).
- When this file's preferences and mathematical correctness conflict, correctness wins.
