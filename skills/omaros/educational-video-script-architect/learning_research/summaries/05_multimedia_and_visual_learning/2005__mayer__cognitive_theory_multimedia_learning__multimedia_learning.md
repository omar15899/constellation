# Core claim

The canonical statement of the **Cognitive Theory of Multimedia Learning (CTML)**. Three assumptions: dual-channel processing (verbal + visual), limited working-memory capacity per channel, and active processing (the learner builds coherent mental models). From these flow a set of well-known design principles: coherence, signaling, redundancy, spatial contiguity, temporal contiguity, segmenting, pre-training, modality, multimedia, personalisation, voice.

# What this paper is useful for in educational video design

The single most directly applicable theoretical source for educational video. Every well-designed Manim or motion-graphics video is implicitly applying CTML — it is worth making the application explicit.

# Actionable principles

Top-impact CTML principles for video:
- **Modality**: voice-over + visual outperforms on-screen text + visual.
- **Redundancy**: voice-over + identical on-screen text *underperforms* either alone.
- **Spatial contiguity**: place labels adjacent to their target.
- **Temporal contiguity**: synchronise narration with the visual event it describes.
- **Signaling**: highlight what to look at.
- **Segmenting**: chunk into discrete scenes with pauses.
- **Coherence**: strip extraneous content.

# How the video-script skill should use this

Every line of the visual-language guide and the visual-quality checklist is downstream of CTML. When a script breaks one of the principles, the violation should be acknowledged and justified.

# Risks / limitations / caveats

CTML is general; some principles (e.g., personalisation) matter less in a maths/physics context where formality has its own value. The *signalling* principle can be over-applied — too many highlights destroy attention.
