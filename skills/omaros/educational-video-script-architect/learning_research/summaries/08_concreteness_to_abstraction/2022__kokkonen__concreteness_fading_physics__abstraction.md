# Core claim

Tests concreteness fading in secondary-school physics, comparing to concrete-only and abstract-only instruction. Fading produces stronger conceptual transfer; the effect is mediated by clearer mappings between physical phenomenon and formal representation.

# What this paper is useful for in educational video design

Most directly relevant to physics-topic videos. Confirms the McNeil & Fyfe / Fyfe et al. result in a domain (physics) where concreteness can be photorealistic and abstraction can be mathematical.

# Actionable principles

1. For physics videos, the concrete stage can be a real-world phenomenon (footage or 3D simulation); the bridge can be a force diagram or schematic; the formal stage is the equation.
2. The *mapping* between stages is what carries the learning — animate the morph rather than cutting between them.
3. Generative video can serve as the concrete stage, but the formal labels are added in post.

# How the video-script skill should use this

When the topic is physical, the script should default to phenomenon → diagram → equation, with explicit morph animations between stages. This is consistent with the production-modality matrix in `SKILL.md` §5.

# Risks / limitations / caveats

Single-domain study; evidence base for physics-specific concreteness fading is still relatively thin. Use as a confirmation of the broader pattern, not as a uniquely strong source.
