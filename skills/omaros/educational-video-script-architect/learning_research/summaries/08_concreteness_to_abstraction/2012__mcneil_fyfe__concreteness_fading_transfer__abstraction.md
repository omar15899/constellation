# Core claim

Compares three conditions for teaching modular arithmetic: concrete-only, abstract-only, and **concreteness-fading** (start concrete, gradually replace surface features with abstract symbols). The fading condition produced the best *transfer* to a novel concrete instance — better than either pure condition.

# What this paper is useful for in educational video design

Empirical anchor for the *concreteness-fading* design pattern: open with a concrete visual, then morph it into the abstract symbolic form, keeping the structural correspondence visible at every step.

# Actionable principles

1. A concrete object opens the explanation; the formal symbol does not.
2. Fade the concrete features only after the structure they embody is visible.
3. The endpoint is the formal object — not a half-concrete intermediate. Stopping at intermediate concreteness gives all the wrong intuitions.

# How the video-script skill should use this

When the topic is mathematical, the script should default to concreteness fading: scene 1 is concrete, scene N is formal, with explicit morph animations between them. The visual-continuity rule in the visual-language guide enforces this.

# Risks / limitations / caveats

Domain-specific evidence (elementary maths). Generalisation to higher mathematics is plausible but not directly tested. Some abstract content (category theory, axiomatic set theory) lacks a natural concrete starting point — be careful not to *invent* a misleading metaphor.
