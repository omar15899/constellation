# Core claim

Systematic review of concreteness-fading studies across maths, physics, and science education. Confirms that gradual fading from concrete to abstract reliably outperforms either pure-concrete or pure-abstract instruction for *transfer* to novel problems. Pure concreteness anchors learning to surface features and inhibits transfer.

# What this paper is useful for in educational video design

The single best citation for *why* the script should not stop at the concrete metaphor stage. Generalises the McNeil & Fyfe (2012) result and provides design guidance on *how much* to fade and *when*.

# Actionable principles

1. Three-stage default: concrete instance → semi-abstract bridge (e.g., schematic diagram) → fully formal object.
2. The bridge stage matters: skipping it loses many learners; lingering in it gives wrong intuitions.
3. Fade *during* the video — not by giving up on abstraction altogether.

# How the video-script skill should use this

When the script's pedagogy mode is example-first or phenomenon-first, the explanatory architecture should include three movements: concrete → bridge → formal. Each transition is a visual morph, not a cut.

# Risks / limitations / caveats

The review's evidence base is K-12 and undergraduate STEM. Research-level mathematics videos may need a different rhythm (formal first, with informal commentary).
