# Core claim

Companion review to the 2006a *Psychological Science* paper. Synthesises a century of testing-effect research and translates it into instructional recommendations: tests are not only *measurement* tools, they are *learning* tools, and they should be used as such throughout instruction.

# What this paper is useful for in educational video design

The conceptual reframing: a question on screen is not an assessment, it is a teaching device. This reframing is what licenses the inclusion of retrieval prompts inside an educational video instead of relegating them to a separate quiz at the end.

# Actionable principles

1. Spread retrieval throughout the video, not only at the end.
2. Vary the format of retrieval (recall, recognition, comparison, classification, prediction) to avoid format-specific learning.
3. Use cued recall (with a small hint) when the viewer is likely to draw a blank; use free recall when retention is robust enough to support it.

# How the video-script skill should use this

Treat *every* scene transition as a retrieval opportunity. Use a varied set of prompt formats across the video so that the testing effect is robust to format-specific encoding. Cite this paper when explaining *why* the script keeps interrupting itself with prompts.

# Risks / limitations / caveats

Some retrieval prompts cost narrative momentum; the script should pick its moments. The benefit is in *retention*, not in *first-pass comprehension*; novice viewers may experience prompts as friction. Pair early prompts with feedback to keep them productive.
