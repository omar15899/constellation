# Core claim

A meta-analysis of 317 experiments across 184 articles. Spacing study sessions (rather than massing them) reliably improves long-term retention. The optimal *gap* between sessions scales with the desired *retention interval*: roughly, optimal gap ≈ 10–30% of the retention interval.

# What this paper is useful for in educational video design

Quantifies the spacing effect at scale. The dose-response curve gives a principled way to recommend gaps in a series-of-videos plan, a curriculum, or even within a single long video where a concept reappears.

# Actionable principles

1. For a viewer who needs to retain material for a week, space related content over hours — not within a single 10-minute block.
2. For series-level planning, the gap between episodes covering the same topic should scale with the intended retention horizon.
3. Within a single video, *re-encountering* a concept after intermediate material is itself a small-scale spacing effect — the script should design for this.

# How the video-script skill should use this

When the user requests a *series*, the skill should propose a spaced re-encounter schedule rather than a topic-pure episode order. When the user requests a *single video*, the skill should re-encounter the central object at least once, after intermediate examples.

# Risks / limitations / caveats

The optimal-gap rule is empirical and approximate. Most studies use verbal materials. Massed practice can outperform spacing on *immediate* tests — be careful in QC: short post-test ≠ long-term benefit.
