# Core claim

*Review of Educational Research* synthesis of the worked-example literature. Worked examples — fully solved demonstrations of a problem — outperform conventional problem-solving when learners are novices, particularly in well-structured domains like algebra and physics. The benefit comes from offloading search-cost so cognitive resources can build schemas.

# What this paper is useful for in educational video design

The strongest single justification for *showing the full solution path* in a video, including the steps a textbook might leave to the reader. For novices, worked examples are not redundant — they are the principal teaching device.

# Actionable principles

1. For novices, fully work through the canonical example before asking for prediction.
2. Use *self-explanation prompts* between worked-example steps ("why did we choose this substitution?") to force germane processing.
3. Pair worked examples with isomorphic problems so the viewer can attempt the structure on a fresh surface.

# How the video-script skill should use this

Beginner and undergraduate scripts should default to the worked-example pattern: example with all steps shown → prediction prompt for an isomorph → revealed solution. Researchers may need only the structural sketch — see Kalyuga (2003) on expertise reversal.

# Risks / limitations / caveats

Worked examples can become passive if the viewer is not prompted to engage. They lose effectiveness as expertise grows (expertise reversal). Worked examples in ill-structured domains (essays, design) are harder to construct.
