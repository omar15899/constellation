# Core claim

Tests **completion-problem fading**: start with a fully worked example, then progressively replace solved steps with blanks the learner must complete, ending with full problem-solving. Outperforms either pure worked examples or pure problem-solving in terms of transfer and efficiency.

# What this paper is useful for in educational video design

The best single source on *how* to transition from showing to asking. The fading sequence is a concrete pedagogical scaffold the script can follow within a single scene or across consecutive scenes.

# Actionable principles

1. First example: fully worked, with self-explanation prompts.
2. Second example: same template with the *last* step left blank for the viewer to complete.
3. Third example: more blanks, fewer scaffolds.
4. Final example: viewer attempts unaided.
The sequence engineers a graduated transfer of agency without the cliff of "now you do one".

# How the video-script skill should use this

When a video is procedural (algorithm, derivation, problem-solving), the second-by-second script should follow the fading sequence rather than presenting one worked example and stopping. Each blank-to-fill is a 2–4 s prompt with answer revealed.

# Risks / limitations / caveats

Fading needs enough examples to actually fade across; very short videos may need to compress the sequence. The viewer's pause-and-think capacity in a non-interactive video is limited — keep prompts short.
