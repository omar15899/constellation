# Core claim

Practical synthesis arguing that mathematics and science instruction routinely uses *blocked practice* (one section, one concept), which is good for short-term performance but bad for long-term discrimination. Interleaving similar problem types substantially improves transfer in maths, even when total practice time is held constant.

# What this paper is useful for in educational video design

The most accessible single source on interleaving in **mathematics-classroom contexts**. Useful when designing videos on topics where viewers must learn to recognise *which technique applies* (definite vs indefinite integration, when to use Itô vs Stratonovich, when to use the chain vs the product rule).

# Actionable principles

1. After introducing two related techniques, interleave problems that require choosing between them.
2. Do not assume a viewer who can apply technique X when told to apply X can also recognise *when* to apply X — that is a separate skill, taught by interleaving.
3. The interleaving cost in subjective fluency is real; in a video, mitigate it by narrating that the difficulty is intentional.

# How the video-script skill should use this

When the topic is procedural and involves choice between techniques, the second-by-second script should include at least one *unmarked* problem (no hint about which technique applies) followed by the viewer making the choice. This is the discrimination moment.

# Risks / limitations / caveats

Interleaving requires the viewer to have *first* encountered each technique in a clean, blocked way — interleaving from the start is too hard. Sequence: block briefly → interleave → free practice.
