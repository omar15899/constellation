# Core claim

Decomposes the interleaving benefit into two mechanisms: (a) **discrimination** — interleaved presentation forces attention to features that distinguish category members; (b) **retrieval** — switching categories forces a small retrieval event each time. The combined effect explains why interleaving outperforms blocking in inductive tasks.

# What this paper is useful for in educational video design

Tells you *why* interleaving works, which lets you design videos that exploit either or both mechanisms intentionally. Discrimination matters for taxonomies; retrieval matters for procedural fluency.

# Actionable principles

1. To exploit *discrimination*: interleave examples that differ on features the viewer must learn to attend to (e.g., distinguish a chart from its underlying manifold).
2. To exploit *retrieval*: switch back to a previously introduced concept in a later scene, forcing the viewer to retrieve it.
3. The two mechanisms can be combined: a scene that interleaves comparisons of A/B with periodic retrieval of A from a much earlier moment in the video.

# How the video-script skill should use this

Pedagogical design notes should explicitly state which mechanism the interleaving serves — discrimination, retrieval, or both. This forces the script to design intentionally rather than rotating examples for variety alone.

# Risks / limitations / caveats

The discrimination mechanism only kicks in when the viewer can actually *see* the discriminating feature — rapid cuts or low-information visuals defeat it.
