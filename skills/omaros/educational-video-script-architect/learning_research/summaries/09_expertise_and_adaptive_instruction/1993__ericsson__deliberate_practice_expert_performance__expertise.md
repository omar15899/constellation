# Core claim

Argues that elite performance in any domain results from *deliberate practice*: focused, effortful, feedback-rich activity at the edge of current capability — not from time-on-task or natural talent. The original 10,000-hour-rule paper (though Ericsson later resisted that simplification).

# What this paper is useful for in educational video design

Indirect but important: a video is one slice of a learner's diet, not a full curriculum. The script should be honest about what a single video can do (introduce, motivate, demonstrate) and what it cannot do (build skill — that requires the learner's own deliberate practice between viewings).

# Actionable principles

1. End-of-video recommendations should point to *deliberate-practice* activities, not just "watch the next video".
2. A video that aims to build skill must include or recommend feedback-rich exercises.
3. The video itself is a *priming* artefact; the actual learning happens in subsequent practice.

# How the video-script skill should use this

When the script's objective is skill acquisition (algorithm execution, derivation fluency, problem-solving), the closing scene should explicitly hand off to a deliberate-practice activity rather than concluding self-sufficiently.

# Risks / limitations / caveats

Deliberate-practice theory is contested as a *complete* explanation of expertise; talent and circumstance matter. The framework is best used as an *additive* claim (deliberate practice is necessary), not a *sufficient* one.
