## Stubs (to be expanded)

The following examples are seeded as descriptions and will be expanded as Omar uses the skill on these topics. Each is included to prevent the canonical example from being treated as a template for *all* topics.

- **`advanced_probability_space_script.md`** *(stub)* — advanced UG / master's, 12:00, Manim 2D + motion graphics. Topic: the construction of the Lebesgue measure on $\mathbb{R}$ and why the Borel σ-algebra is the right domain for it. Pedagogy: problem-first (intervals are not enough) → diagnosis (need closure under countable operations) → construction (Carathéodory) → recovery (Borel and Lebesgue measurable sets) → leverage (integration that respects limits).
- **`research_stochastic_integral_script.md`** *(stub)* — research / expert, 18:00, Manim 2D heavy with custom path animations. Topic: why the Itô integral is not the limit of Riemann sums in the obvious sense and what it actually is. Pedagogy: theorem → intuition → naïve attempt fails → construction via $L^2$-isometry → consequences (Itô formula).
- **`hybrid_ai_video_fourier_transform_script.md`** *(stub)* — mixed audience, 8:00, hybrid (Manim + generative video for cinematic context). Topic: the Fourier transform as decomposition into frequencies, leading to the inversion theorem. Pedagogy: phenomenon-first (a signal that hides simple structure) → decomposition → reconstruction → leverage (filtering, convolution).
