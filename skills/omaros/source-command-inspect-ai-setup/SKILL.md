# /inspect-ai-setup

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Read `ai-setup-inspector`. Resolve the target and identifier; inspect the target
without modifying it. Inventory native entry points, central profiles, agents,
skills, hooks, permissions and active automation. Distinguish configured,
discoverable, trusted and executed states. Compare against an earlier manifest
when one exists. Count secret-shaped files using metadata but never open or hash
them. Report scan truncation and do not claim exhaustive coverage.

A requested saved audit uses `07_AI_and_Agents/Setup_Audits/Targets/<id>/` for the
report, manifest and history, and updates the related audit indexes. A chat-only
audit stays in chat. Assess quality by effective behavior and evidence, not by
the number of agents, registries or hooks installed.
