# /refresh-external-setups

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Read `external-setups-mirror` and its script interface before executing.
Restrict the request to named, authorized projects; a registry entry alone does
not authorize inspecting unrelated files. Preview the file list before any
snapshot. Exclude secrets, conversations, manifests containing conversation data,
private runtime state and daemon logs. A snapshot under
`07_AI_and_Agents/External_Setups/` is reference material, never a second active
Constellation installation. Do not copy central source code merely to mirror it.

`--dry-run` reports without writing; `--only SLUG` restricts scope. Missing
sources retain their prior snapshot with a visible stale status. `--prune`
requires authorization for the exact removals. Never automatically publish
snapshots or enable recurring mirroring.
