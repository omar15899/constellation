# /task

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Read [task-marshal](../task-marshal/SKILL.md). The default verb is `log`.
Supported operations include close, cancel, block, waiting, rollover, query,
report, report-tag, reclassify and tags; use the existing deterministic scripts
for the operation. Every independent bullet becomes one task. Preserve the
original body and user tags, leave unspecified fields null, and retain state
history. Ledger data lives under `02_Tasks_and_Execution/Ledger/`; regenerate its
views after a write. Query and report-in-chat requests do not authorize unrelated
ledger edits or publication.
