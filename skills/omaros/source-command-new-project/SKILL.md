# /new-project

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Search for an existing project before creating `05_Projects/<name>/`. Use the
requested name, a kebab-case folder and Title Case frontmatter unless the
project's established naming convention differs. Create its README first as the
map of content, then the requested Vision.md, Status/, Decisions/, Checkpoints/,
Risks.md and Tasks.md. Preserve known facts and mark missing scope rather than
inventing goals or risks. Use `project-reporter` for the project note and update
navigation only where needed.
