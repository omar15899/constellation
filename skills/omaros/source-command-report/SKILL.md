# /report

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Resolve report type and subject, locate the relevant sources, and use
`writter` with the domain method needed. Typical report subdirectories under
`11_Documents_and_Reports/` are Research/, Projects/, Weekly/, Finance/ and AI/.
Prefer the project's existing canonical note when it should be extended.
Every factual claim must trace to available evidence; label synthesis,
uncertainty and missing data. A request for a report in conversation does not
authorize saving or publication.
