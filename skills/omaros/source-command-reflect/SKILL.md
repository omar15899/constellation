# /reflect

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Read `scholar` or `writter` as appropriate and preserve the user's thesis and
voice. Discuss the seed in conversation when that is the request. A requested
saved reflection belongs in `01_Daily_Life/Reflections/` for personal seeds or
`04_Research/Essays/` for a structured argument, after checking existing content.
Do not moralize or give unsolicited advice. Distinguish supplied experience,
interpretation and speculation. Ask only when a missing choice materially
changes the note; do not invent an intended stance.
