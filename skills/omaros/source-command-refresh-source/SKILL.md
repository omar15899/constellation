# /refresh-source

Use the [common Constellation entry](../../../README.md) for scope, evidence,
independent review and publication. Resolve consultations directly; open a scoped
assignment before a change. Domain names below identify skills or responsibilities;
use the native agent catalogue for delegation, inherit the session settings, and
leave Git integration and publication to the coordinator. Project data paths are
relative to `/Users/omarkhalil/OmarOS` unless an absolute path is given.

Resolve the exact source identifier in
`20_System_Governance/Sources/sources.yaml`; show possible matches for an unknown
identifier. Honor source-specific access and refresh permission. Check
reachability and change: unreachable is failed, unchanged needs no ingestion.
Use its available import skill for changed authorized input, then update
`11_Documents_and_Reports/Source_Status/<source_id>.md`. Report failures with
concrete evidence; write an incident only when included in scope. Do not cascade
to related sources. The source's SLA describes freshness, not permission to
schedule or activate an automation.
